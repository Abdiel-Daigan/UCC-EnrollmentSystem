UNIDA CHRISTIAN COLLEGE ENROLLMENT SYSTEM

INSTALLATION:
1. Install XAMPP.
2. Extract this folder into C:\xampp\htdocs\
3. Start Apache and MySQL.
4. Go to http://localhost/phpmyadmin
5. Import database/unida_enrollment.sql
6. Open http://localhost/unida_christian_college/

LOGIN:
Username: admin
Password: admin123

FEATURES:
Dashboard, student registration/search/delete, subject management,
enrollment creation, automatic unit calculation, approval, and records.

This is an educational/local-host starter project. Production deployment
should add password hashing, role-based access, CSRF protection,
server-side validation, audit logs, and secure database credentials.
